# CYBER PSYCHE · 神经类型扫描

赛博朋克风格的综合人格测试 Web 应用。一次扫描，输出五重人格矩阵：

- **MBTI** 神经类型（16 型）
- **大五人格** OCEAN 五维
- **九型人格** Enneagram（含翼型）
- **DnD 阵营** 九宫格道德立场
- **本能复型** SP / SX / SO

## 特点

- 72 题综合题库，每题映射多个维度，约 8 分钟完成
- 全部在浏览器本地计分，数据不上传
- 赛博朋克视觉：霓虹配色、扫描线、网格背景

## 分享结果

测完后在结果页底部可以：

- **复制链接** — 链接内编码了完整答题数据，好友打开即可看到相同结果
- **复制分享文案** — 适合粘贴到微信、微博等
- **系统分享** — 手机端一键调起原生分享面板

分享链接格式：`https://你的域名/#share=xxxxx`

好友打开后会看到完整神经档案，并可点击「我也测一测」开始自己的测试。

## 快速开始

```bash
cd cyber-psyche
npm install
npm run dev
```

浏览器打开终端显示的本地地址（通常是 `http://localhost:5173`）。

## 构建部署

```bash
npm run build
npm run preview
```

`dist/` 目录可部署到任意静态托管（Vercel、Netlify、GitHub Pages 等）。
